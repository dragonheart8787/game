## 問題 1:重開 Editor 後「退化」— 白色人偶 + WASD 全滅

**症狀**:角色是灰白人偶、WASD 完全沒反應,但 ` 可開主控台。
初始假設(GameMode 生成裸 C++ pawn、StaticLoadClass 失效)經 log 驗證**不成立**
—— 三次獨立實測 pawn 都是 `BP_NovaCharacter_C`、9 個 Input Action + IMC 全數綁定。

**真正的根因(三個獨立問題疊加)**:

1. **引擎關聯懸空**:`.uproject` 從第一個 commit 就用 source-build 式的 GUID
   `EngineAssociation`,但 HKCU 的 Builds 登錄是空的,而 D:\UE_5.8 其實是
   **Epic Launcher 安裝版**。每次檔案總管開 .uproject 就跳 Convert Project、
   右鍵 rebuild 容易對錯引擎 → 「Missing MyProject Modules」。
   修法:`"EngineAssociation": "5.8"`。
2. **WASD 全滅 = IMC 資料躺錯槽位**:`IMC_NovaDefault` 的 12 條映射存在
   **UE 5.7 已棄用的 `Mappings` 屬性**,而 5.8 執行時只讀
   `DefaultKeyMappings.Mappings`(空)。`PostLoad()` 的自動遷移只認「舊引擎
   序列化的資產」,5.8 存的資產永遠不遷移。禍源:當初用 Editor Python 反射
   寫入 `mappings`(寫入不報錯),而不是 `MapKey()` API。
   診斷關鍵工具:`-ExecCmds="showdebug enhancedinput"` 直接顯示
   「No enhanced player input action mappings have been applied」。
   修法:commandlet 把 12 條映射搬進 `DefaultKeyMappings` 後存檔。
3. **白色人偶/螢光綠地板 = 不是 bug**:`SKM_Quinn_Simple` 本色就是灰白;
   綠色是模板 `MI_ThirdPersonColWay` 材質(出生點圓柱平台)+ Story 觸發區
   綠色線框。引擎重建後 DDC 全冷,第一次跑 shader 還在編譯會短暫顯示
   fallback 材質,自癒。整張關卡 dump 確認**零缺失材質、零載入錯誤**。

**教訓**:
- 「console 開得起來」不能證明按鍵有進到遊戲輸入系統(console 在 viewport 層攔截)。
- 程式碼綁定全部成功 ≠ Enhanced Input 有生效映射 — 兩層之間還有 IMC 內容
  與 Input Mode 過濾(5.8 預設 `bEnableInputModeFiltering=true`,空 query 的
  `FGameplayTagQuery::Matches()` 回傳 false)。
- 程式化建立 Enhanced Input 資產:一律用 `MapKey()` 或寫 `default_key_mappings`。

## 問題 2:空中 Dash 無限飛行

**症狀**:地面 Dash 正常,空中觸發後不受控直飛到落地。

**根因**:`LaunchCharacter` 必定切到 Falling 模式,而 Falling 的
`FallingLateralFriction` 與 `BrakingDecelerationFalling` 預設皆 0 —— 空中沒有
任何機制衰減 2500 cm/s 的水平衝刺速度。地面「看起來正常」只是因為立刻落地、
走路摩擦把速度殺掉。重力從未被覆蓋,缺的是「衝刺結束」。

**修法**:`Dash()` 設一次性 timer,`DashDurationSeconds`(0.2s,BP 可調)後
`EndDash()` 把水平速度上限收回 `MaxWalkSpeed`(`GetClampedToMaxSize2D`,Z 不動)。
Review 補強:`ClampMin` + 程式端 `FMath::Max(…, 0.05f)` 防除零與
`SetTimer(rate<=0)` 不觸發(BP 寫入會繞過 ClampMin)。

**實測**:log `EndDash: lateral speed 2500 capped to 500` 地面/空中各一次;
空中 Dash 落點恰好驗證了 Story A 觸發區 + Director 節拍照時序推進。
