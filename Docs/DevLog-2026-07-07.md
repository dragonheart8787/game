## Code review 修正(medium,2 findings 皆 PLAUSIBLE,已修)

1. **正確性**:`ElementAbilityComponent::BeginPlay` 無條件把 `AbilityAssets`
   當成 revert 基準快照。若有早於 BeginPlay 的呼叫先套用 Full override
   (SetAbilityLoadout 已改寫 AbilityAssets),BeginPlay 會把「override 後的
   loadout」誤存為 default → revert 永遠還原成 override 而非 Slash+Edgewall。
   修法:`BeginPlay` 與 `SetAbilityLoadout` 都只在 `DefaultAbilityAssets`
   為空時才快照,確保「BeginPlay 之前的第一次換裝」仍記錄真正的預設。
2. **正確性**:`ApplyFullOverride` 先 `SetOverride`(內部廣播
   `OnIdentityChanged`)才設 `bDashLocked` 與換 loadout → 綁定該事件的
   HUD/BP 讀到的是舊身分狀態(dash=free、舊技能列)。修法:把 dash lock 與
   loadout swap 移到 `SetOverride` 之前,listener 觀察到的即為新身分狀態。

驗證:重編 exit 0;PIE 迴歸重跑一輪,含被動到的 Full→revert 還原路徑
(`loadout reset → 2 abilities (Slash Edgewall)`、`F.normalcast Dmg=20`)全綠。

## 基礎設施筆記

- 關卡 `Lvl_ThirdPerson` 其實**存有一隻** `NovaDummyTarget`(7/6 的 lens
  viewtarget UAID 在編輯器重啟後仍存在 = 已入關卡包)。MCP `find_actors`
  以 **label** 過濾而非 object name,label 不含 "NovaDummyTarget" 時會漏找
  —— 今日因此多生成一隻,測後已移除,關卡未存檔。
- Epic MCP plugin 是 lazy registration:頂層只有 `list_toolsets` /
  `describe_toolset` / `call_tool` 三個工具,實際呼叫都走
  `call_tool{toolset_name, tool_name, arguments}`;`describe_toolset` 的參數
  名是 `toolset_name`。
- `EditorAppToolset.StartPIE` 會等 `PostPIEStarted` 才回傳,搭配
  `warmupSeconds:0` + 固定 sleep 即可做定時序列迴歸,全程免 SlateInspector。
